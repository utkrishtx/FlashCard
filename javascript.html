Introduction to JavaScript

JavaScript is a high-level programming language mainly used to make web pages interactive and dynamic.

It is commonly used in web development, web applications, games and server-side programming.

Who Created JavaScript?

JavaScript was created by Brendan Eich in 1995.

Features of JavaScript

  • Easy to learn and use
  • Makes websites interactive
  • Runs in web browsers
  • Supports event handling
  • Supports object-oriented programming
  • Can also run on servers using Node.js

1. JavaScript Syntax

JavaScript syntax defines the rules for writing JavaScript programs. 

console.log("Hello World!");

Output:

Hello World!

2. Variables and Data Types

Variables are used to store data. JavaScript provides let, const and var. 

let name = "Rahul";
let age = 20;
let price = 99.50;
let isStudent = true;

console.log(name);
console.log(age);

Common Data Types

  • String - Text
  • Number - Numeric values
  • Boolean - True or False
  • Undefined - Value not assigned
  • Null - Intentional empty value
  • Object - Collection of related data

3. JavaScript Operators

  • Arithmetic Operators (+, -, *, /, %)
  • Comparison Operators (==, ===, !=, >, <)
  • Logical Operators (&&, ||, !)
  • Assignment Operators (=, +=, -=)

4. Conditional Statements

Conditional statements are used to make decisions in a program. 

let age = 18;

if (age >= 18) {
    console.log("You are eligible");
} else {
    console.log("You are not eligible");
}

5. JavaScript Loops

Loops repeat a block of code.

For Loop

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

While Loop

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

6. JavaScript Functions

Functions are reusable blocks of code that perform a particular task. 

function greet() {
    console.log("Welcome to JavaScript");
}

greet();

7. JavaScript Arrays

Arrays are used to store multiple values in a single variable. 

let subjects = ["Python", "HTML", "CSS"];

console.log(subjects[0]);
console.log(subjects[1]);

8. DOM Manipulation

DOM stands for Document Object Model. JavaScript can use the DOM to change HTML content and elements. 

document.getElementById("demo").innerHTML =
"Hello JavaScript!";
