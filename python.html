Introduction to Python

Python is a high-level, interpreted and general-purpose programming language.

It is widely used in web development, artificial intelligence, data science, automation and software development.

Who Created Python?

Python was created by Guido van Rossum and was first released in 1991.

Features of Python

  • Easy to learn and understand
  • Simple and readable syntax
  • Free and open source
  • Platform independent
  • Large collection of libraries
  • Supports object-oriented programming

1. Python Syntax

Example of a simple Python program:

print("Hello World!")

Output:

Hello World!

2. Variables and Data Types

Variables are used to store information in a program. 

name = "Rahul"
age = 20
price = 99.50
is_student = True

print(name)
print(age)

Common Data Types

  • int - Integer numbers
  • float - Decimal numbers
  • str - Text values
  • bool - True or False values

3. Python Operators

  • Arithmetic Operators (+, -, *, /)
  • Comparison Operators (==, !=, >, <)
  • Logical Operators (and, or, not)
  • Assignment Operators (=, +=, -=)

4. Conditional Statements

Conditional statements help make decisions.

age = 18

if age >= 18:
    print("You are eligible")
else:
    print("You are not eligible")

5. Python Loops

Loops are used to repeat a block of code.

For Loop

for i in range(5):
    print(i)

While Loop

i = 1

while i <= 5:
    print(i)
    i += 1

6. Python Functions

Functions are reusable blocks of code that perform a particular task. 

def greet():
    print("Welcome to Python")

greet()
