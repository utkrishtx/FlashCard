Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to style and design HTML web pages.

CSS controls colors, fonts, spacing, layouts, backgrounds and animations.

Who Created CSS?

CSS was first proposed by Håkon Wium Lie in 1994.

Features of CSS

  • Controls website appearance
  • Separates design from HTML structure
  • Provides different colors and fonts
  • Supports responsive web design
  • Helps create attractive layouts
  • Supports animations and transitions

1. CSS Syntax

CSS syntax consists of a selector and a declaration block. 

h1 {
    color: purple;
    font-size: 30px;
}

Explanation

  • h1 - Selector
  • color - Property
  • purple - Value
  • font-size - Property
  • 30px - Value

2. CSS Selectors

CSS selectors are used to select HTML elements for styling.

Element Selector

p {
    color: blue;
}

Class Selector

.heading {
    color: purple;
}

ID Selector

#title {
    font-size: 25px;
}

3. CSS Colors and Backgrounds

CSS provides different ways to add colors and backgrounds to web pages. 

body {
    background-color: black;
}

h1 {
    color: purple;
}

Common Color Properties

  • color
  • background-color
  • opacity

4. CSS Box Model

Every HTML element can be represented as a rectangular box.

Four Parts of Box Model

  • Content - Actual content
  • Padding - Space around content
  • Border - Boundary around padding
  • Margin - Space outside the border
div {
    width: 200px;
    padding: 20px;
    border: 2px solid purple;
    margin: 10px;
}

5. CSS Fonts and Text

CSS provides properties to change font style, size and alignment. 

h1 {
    font-family: Arial;
    font-size: 30px;
    font-weight: bold;
    text-align: center;
}

Common Text Properties

  • font-family
  • font-size
  • font-weight
  • text-align
  • text-decoration

6. CSS Flexbox

Flexbox is used to arrange elements in rows or columns. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

Important Flexbox Properties

  • display
  • flex-direction
  • justify-content
  • align-items
  • flex-wrap
  • gap
