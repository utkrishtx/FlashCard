Introduction to DSA

DSA stands for Data Structures and Algorithms. It is an important concept in computer science and programming.

Data structures help organize and store data, while algorithms provide step-by-step methods to solve problems.

Why Learn DSA?

  • Improves problem-solving skills
  • Helps write efficient programs
  • Useful for coding interviews
  • Helps understand programming concepts

Features of DSA

  • Organizes data efficiently
  • Improves program performance
  • Reduces unnecessary operations
  • Helps solve complex problems
  • Supports efficient searching and sorting
  • Useful in software development

1. Arrays

An array is a data structure used to store multiple elements of the same data type. 

int numbers[5] = {10, 20, 30, 40, 50};

cout << numbers[0];

Output:

10

Important Points

  • Stores multiple values
  • Uses index numbers
  • Index starts from 0
  • Elements can be accessed using their index

2. Linked Lists

A linked list is a linear data structure made up of nodes.

Each node contains data and a link to the next node.

Types of Linked Lists

  • Singly Linked List
  • Doubly Linked List
  • Circular Linked List
10 → 20 → 30 → 40 → NULL

3. Stack

A stack is a linear data structure that follows LIFO.

LIFO means Last In First Out.

Basic Stack Operations

  • Push - Add an element
  • Pop - Remove the top element
  • Peek - View the top element
Top → 30
      20
      10

4. Queue

A queue is a linear data structure that follows FIFO.

FIFO means First In First Out.

Basic Queue Operations

  • Enqueue - Add an element
  • Dequeue - Remove an element
  • Front - View the first element
  • Rear - View the last element
Front → 10 → 20 → 30 ← Rear

5. Searching Algorithms

Searching algorithms are used to find a particular element in a collection.

Linear Search

Linear search checks each element one by one until the target is found. 

int arr[5] = {10, 20, 30, 40, 50};

int target = 30;

for (int i = 0; i < 5; i++) {

    if (arr[i] == target) {

        cout << "Element Found";

    }

}

Binary Search

Binary search repeatedly divides a sorted collection into two halves.

  • Works on sorted data
  • Reduces the search area by half
  • Time complexity is O(log n)

6. Sorting Algorithms

Sorting means arranging data in a particular order.

Common Sorting Algorithms

  • Bubble Sort
  • Selection Sort
  • Insertion Sort
  • Merge Sort
  • Quick Sort

Bubble Sort Example

int arr[5] = {5, 3, 4, 1, 2};

for (int i = 0; i < 5; i++) {

    for (int j = 0; j < 4 - i; j++) {

        if (arr[j] > arr[j + 1]) {

            int temp = arr[j];

            arr[j] = arr[j + 1];

            arr[j + 1] = temp;

        }

    }

}

Sorted Array:

1 2 3 4 5

7. Trees

A tree is a non-linear data structure that organizes data in a hierarchical form.

Important Tree Terms

  • Root - Top node of a tree
  • Parent - A node with child nodes
  • Child - A node connected below a parent
  • Leaf - A node with no children
  • Edge - Connection between two nodes
        10
       /  \
      20   30
     / \
    40  50

8. Graphs

A graph is a non-linear data structure consisting of vertices and edges.

Important Graph Terms

  • Vertex - A node in a graph
  • Edge - Connection between vertices
  • Directed Graph - Edges have direction
  • Undirected Graph - Edges have no direction

Graph Traversal

  • BFS - Breadth First Search
  • DFS - Depth First Search
