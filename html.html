Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure of web pages.

HTML uses different tags and elements to organize text, images, links, tables and forms.

Who Created HTML?

HTML was created by Tim Berners-Lee in 1991.

Features of HTML

  • Easy to learn and understand
  • Used to create web page structure
  • Supports images and hyperlinks
  • Works with CSS and JavaScript
  • Supported by all major web browsers
  • Free and open standard

1. HTML Document Structure

Every HTML page follows a basic structure.

<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Hello World</h1>
</body>
</html>

2. HTML Tags and Elements

HTML tags are used to define different parts of a web page. 

<h1>Welcome</h1>
<p>This is my first webpage.</p>

Common HTML Tags

  • h1 to h6 - Headings
  • p - Paragraph
  • br - Line Break
  • hr - Horizontal Line
  • div - Container
  • span - Inline Container

3. HTML Attributes

Attributes provide additional information about HTML elements. 

<a href="https://example.com">
    Visit Website
</a>

Common Attributes

  • href - Specifies a link
  • src - Specifies an image source
  • alt - Alternative image text
  • id - Unique element identifier
  • class - Groups elements for styling

4. Headings and Paragraphs

HTML provides six heading levels.

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Small Heading</h3>

<p>This is a paragraph.</p>

5. HTML Links and Images

Creating a Link

<a href="https://www.google.com">
    Visit Google
</a>

Adding an Image

<img src="image.jpg" alt="Sample Image">

6. HTML Lists and Tables

Unordered List

<ul>
    <li>Python</li>
    <li>HTML</li>
    <li>CSS</li>
</ul>

Ordered List

<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
</ol>

HTML Table

<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
    <tr>
        <td>Rahul</td>
        <td>20</td>
    </tr>
</table>

7. HTML Forms

Forms are used to collect information from website visitors. 

<form>

    <label>Name:</label>
    <input type="text">

    <label>Email:</label>
    <input type="email">

    <button type="submit">
        Submit
    </button>

</form>
