Introduction to C++

C++ is a general-purpose programming language used to develop software, games, operating systems and applications.

It supports procedural programming and object-oriented programming.

Who Created C++?

C++ was developed by Bjarne Stroustrup and first appeared in 1985.

Features of C++

  • Object-oriented programming
  • Fast and efficient execution
  • Supports functions and classes
  • Platform independent source code
  • Supports memory management
  • Rich standard library

1. C++ Syntax

Every C++ program follows a basic structure. 

#include <iostream>
using namespace std;

int main() {

    cout << "Hello World!";

    return 0;
}

Output:

Hello World!

2. Variables and Data Types

Variables are used to store information in a program. 

#include <iostream>
using namespace std;

int main() {

    int age = 20;
    float price = 99.50;
    char grade = 'A';
    string name = "Rahul";

    cout << name;

    return 0;
}

Common Data Types

  • int - Integer numbers
  • float - Decimal numbers
  • double - Large decimal values
  • char - Single character
  • string - Text values
  • bool - True or False

3. C++ Operators

  • Arithmetic Operators (+, -, *, /, %)
  • Comparison Operators (==, !=, >, <)
  • Logical Operators (&&, ||, !)
  • Assignment Operators (=, +=, -=)
int a = 10;
int b = 5;

cout << a + b;

Output:

15

4. Conditional Statements

Conditional statements help a program make decisions. 

int age = 18;

if (age >= 18) {

    cout << "You are eligible";

}
else {

    cout << "You are not eligible";

}

5. C++ Loops

Loops are used to repeat a block of code.

For Loop

for (int i = 1; i <= 5; i++) {

    cout << i << endl;

}

While Loop

int i = 1;

while (i <= 5) {

    cout << i << endl;

    i++;

}

Do-While Loop

int i = 1;

do {

    cout << i << endl;

    i++;

} while (i <= 5);

6. C++ Functions

Functions are reusable blocks of code that perform a particular task. 

#include <iostream>
using namespace std;

void greet() {

    cout << "Welcome to C++";

}

int main() {

    greet();

    return 0;
}

7. C++ Arrays

Arrays store multiple values of the same data type in a single variable. 

int numbers[5] = {10, 20, 30, 40, 50};

cout << numbers[0];

Output:

10

8. Object-Oriented Programming

OOP is a programming approach based on classes and objects.

Class and Object Example

#include <iostream>
using namespace std;

class Student {

public:

    string name = "Rahul";

    void display() {

        cout << name;

    }

};

int main() {

    Student s1;

    s1.display();

    return 0;
}

Important OOP Concepts

  • Class
  • Object
  • Inheritance
  • Polymorphism
  • Encapsulation
  • Abstraction
